# 关于我们页面浅色主题渐变背景更新

## 更新内容

### 1. 主题渐变配置修改

#### 浅色主题渐变背景更新
在 `useTheme.js` 中修改了浅色主题的 `--gradient-bg-hero` 变量：

```javascript
// 修改前
'--gradient-bg-hero': 'linear-gradient(135deg, #ffecd2 0%, #fcb69f 100%)'

// 修改后
'--gradient-bg-hero': 'linear-gradient(135deg, #ffffff 0%, #e6f3ff 100%)'
```

### 2. 渐变效果对比

#### 修改前（暖色调渐变）
- **起始颜色**：浅橙色 (`#ffecd2`)
- **结束颜色**：暖橙色 (`#fcb69f`)
- **特点**：温暖、舒适的暖色调渐变
- **视觉效果**：偏向橙色系，给人温暖感

#### 修改后（白色到浅蓝渐变）
- **起始颜色**：纯白色 (`#ffffff`)
- **结束颜色**：浅蓝色 (`#e6f3ff`)
- **特点**：清新、干净的冷色调渐变
- **视觉效果**：偏向蓝色系，给人清新感

### 3. 渐变技术细节

#### CSS 渐变语法
```css
linear-gradient(135deg, #ffffff 0%, #e6f3ff 100%)
```

- **方向**：135度对角线渐变
- **起始点**：0% 位置为纯白色
- **结束点**：100% 位置为浅蓝色
- **过渡**：平滑的颜色过渡

#### 颜色值分析
- **#ffffff**：纯白色，RGB(255, 255, 255)
- **#e6f3ff**：浅蓝色，RGB(230, 243, 255)
  - 红色分量：230（较高）
  - 绿色分量：243（很高）
  - 蓝色分量：255（最高）

### 4. 主题对比效果

#### 深色主题（保持不变）
```css
'--gradient-bg-hero': 'linear-gradient(135deg, #0A0A1A 0%, #1a1a2e 100%)'
```
- **起始颜色**：深蓝色 (`#0A0A1A`)
- **结束颜色**：深灰色 (`#1a1a2e`)
- **特点**：深色科技感渐变

#### 浅色主题（已更新）
```css
'--gradient-bg-hero': 'linear-gradient(135deg, #ffffff 0%, #e6f3ff 100%)'
```
- **起始颜色**：纯白色 (`#ffffff`)
- **结束颜色**：浅蓝色 (`#e6f3ff`)
- **特点**：清新明亮渐变

### 5. 应用范围

#### 关于我们页面
- **页面容器**：`.about-page` 类使用 `var(--gradient-bg-hero)`
- **背景效果**：整个页面背景应用渐变
- **响应式**：所有屏幕尺寸都显示渐变背景

#### CSS 应用方式
```css
.about-page {
  background: var(--gradient-bg-hero);
  min-height: 100vh;
  transition: background 0.3s ease;
}
```

### 9. 自定义选项

#### 调整渐变颜色
如果需要进一步调整渐变效果，可以修改颜色值：

```javascript
// 更浅的蓝色渐变
'--gradient-bg-hero': 'linear-gradient(135deg, #ffffff 0%, #f0f8ff 100%)'

// 更深的蓝色渐变
'--gradient-bg-hero': 'linear-gradient(135deg, #ffffff 0%, #d1e7ff 100%)'

// 不同角度的渐变
'--gradient-bg-hero': 'linear-gradient(90deg, #ffffff 0%, #e6f3ff 100%)'
```

#### 调整渐变方向
```javascript
// 垂直渐变
'--gradient-bg-hero': 'linear-gradient(180deg, #ffffff 0%, #e6f3ff 100%)'

// 水平渐变
'--gradient-bg-hero': 'linear-gradient(90deg, #ffffff 0%, #e6f3ff 100%)'

// 径向渐变
'--gradient-bg-hero': 'radial-gradient(circle, #ffffff 0%, #e6f3ff 100%)'
```
